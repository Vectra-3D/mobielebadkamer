# mobielebadkamer.info — redesign

A static rebuild of all six pages, same URLs as the WordPress site. No WordPress, plugins, jQuery or Google Fonts calls; works opened straight from disk or on any web host.

## View it
Open `index.html` in a browser. To go live, upload the whole folder to the web root.

## The request form
By default **Aanvraag versturen** opens the visitor's mail app with a pre-filled email to info@mobielebadkamer.info. To receive requests directly instead, create a form endpoint (Formspree, Basin, Netlify Forms or your own PHP mailer) and paste its URL into `FORM_ENDPOINT` at the top of `assets/js/site.js`.

## Editing
Pages are generated by `_source/build.py` (shared header, footer, FAQ and prices live there once). Edit and run `python3 _source/build.py` (needs Pillow), or edit the HTML files directly.
